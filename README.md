# Customer Churn & CLV Analysis Project

## Overview
This project predicts customer churn and calculates customer lifetime value (CLV).

## Tools Used
- Python (Pandas, Scikit-learn)
- Power BI

## Features
- Churn Prediction Model
- CLV Calculation
- Customer Segmentation
- Interactive Dashboard

## Folder Structure
- data/
- scripts/
- notebooks/
- powerbi/
- reports/

## How to Run
1. Run data_generation.py
2. Run data_cleaning.py
3. Run model_training.py
4. Run clv_segmentation.py
